Qyflux 首个预编译版本，适用于 **Windows 10 / 11 x64**。

### 下载哪个文件？

- **`Qyflux-v0.1.0-windows-x64.zip`**：推荐。解压后双击 `Qyflux.exe`，附使用说明与字体许可证。
- **`Qyflux-v0.1.0-windows-x64.exe`**：直接下载单文件程序运行。
- `SHA256SUMS.txt`：上述两个文件的 SHA-256 校验值。
- GitHub 自动提供的 `Source code` 是源码，普通用户无需下载。

### 主要功能

- `Alt + Space` 呼出黑底环形工具箱，支持标签、滚轮切换、多层应用环与扇区高亮。
- 主程序管理应用、文件与文件夹快捷方式。
- 独立桌面区域，支持底色、不透明度、位置和尺寸设置。
- 自定义主题色、玻璃材质、背景图片、光效与动效。
- Windows Shell 高清图标、图标缓存与快捷方式内部副本。
- 托盘常驻，可选开机自启动；配置保存在本机。

### 运行说明

- 无需安装 Rust 或 Node.js，需要 **Microsoft Edge WebView2 Runtime**。缺少时可从 [Microsoft 官方页面](https://developer.microsoft.com/microsoft-edge/webview2/) 安装。
- 本版本为免安装应用，设置保存在 `%APPDATA%/studio.qyflux.desktop/`，不随程序文件一起移动。
- 更新时先从托盘退出旧版本，再替换程序；原有配置会保留。
- 当前版本未进行代码签名。

### 已知限制

- 桌面区域为独立浮窗，系统「显示桌面」可能将其隐藏。
- 玻璃材质取决于系统版本与透明效果设置。
- 若 `Alt + Space` 被占用，可通过托盘打开工具箱。
